# What's New

This section tracks project evolution across released changes, in-flight plans, and proposed enhancements.

## In this section

- [Changelog](changelog.md), released changes and development updates
- [Roadmap](roadmap.md), near-term and longer-term planned work
- [Maestro Enhancement Proposals](proposals/index.md), draft and accepted enhancement proposals for select roadmap items

## How to use this section

- If you want to see what changed in a release, start with the changelog.
- If you want to see what may be coming next, review the roadmap and enhancement proposals
- If you want design and decision history for larger changes, review proposals.

## Notes

Development documentation builds may include unreleased changes collected from changelog fragments. Released versions of the documentation reflect the changelog content committed for that release.
